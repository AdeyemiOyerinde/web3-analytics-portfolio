### 1. Solana Memecoin Market Intelligence

**Focus:** DEX trading behavior and token lifecycle analysis

| | |
|---|---|
| **Questions** | Are volumes driven by real demand or speculation? Which tokens show sustained trader participation? |
| **Methods** | SQL on-chain extraction, daily aggregation, trader segmentation, interactive dashboarding |
| **Stack** | `SQL` `Streamlit` |
